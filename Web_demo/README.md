## 1. Web Demo Server (Dành cho Bộ Quét - Thành viên 2)
Web demo cục bộ được dựng bằng thư viện chuẩn `http.server` của Python để thử nghiệm các kịch bản kiểm thử HTTP Security Headers và Cookie Attributes.

### Chạy web thử nghiệm

Chạy từ thư mục gốc của repo.

```text
python Web_demo/app.py
```

Xem [README của dự án](../README.md#chạy-demo-tích-hợp) để quét, mở dashboard và xuất báo cáo.
